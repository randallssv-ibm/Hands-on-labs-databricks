# Databricks Academy

**A collaborative learning repository for building, improving, and sharing solutions in Databricks.**

## 📌 Purpose

Databricks Academy is a centralized hub of practical knowledge that:
- Provides structured labs for learning Databricks from scratch
- Offers working demos that demonstrate real-world use cases
- Establishes a reusable base architecture (Medallion)
- Enables teams to continuously iterate and improve

It's not just documentation: it's code, demos, and knowledge ready to deploy, replicate, and evolve.

## 📂 Repository Structure

| Folder | Description |
| --- | --- |
| `/agents` | AI Agents labs and demos for financial analysis, operational insights, and more |
| `/data-pipeline` | Ingestion, transformation, and modeling of operational data |
| `/architecture` | Medallion Pattern (Bronze/Silver/Gold), data catalog, and base scripts |
| `/demos` | Complete, functional use cases ready for reuse |
| `/docs` | Step-by-step guides, technical documentation, and best practices |
| `/scripts` | Reusable scripts for setup, initialization, and automation |

## 🎯 How to Use This Repository

1. **Learn:** Review the `/labs` and follow the guides in `/docs`
2. **Explore:** Check out `/demos` to see use cases in action
3. **Build:** Use `/scripts` and `/architecture` as a starting point
4. **Improve:** Replicate, customize, and contribute your improvements

## 📊 Initial Use Cases

- **Financial Analysis AI Agent:** Analyzes budget consumption by cost center
- **Data Pipelines:** Ingestion and modeling of operational data
- **Scalable Architecture:** Structured foundation based on the Medallion pattern

## 🔄 Philosophy

This repository grows **iteratively and organically**:
- Teams take what exists
- They replicate, improve, and evolve it
- They contribute new capabilities
- Knowledge is amplified and reused

**Databricks Academy is a project alive, not a static artifact.**
